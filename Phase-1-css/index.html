CSS stands for Cascading Style Sheets.

describes how the web page will be displayed on the screen.
It is used for styling the web pages.CSS saves a lot of work.
It can control the layout of multiple web pages all at once.
There are 3 types of css.

1.Inline css:Written directly inside an HTML tag using the style attribute. 2.Internal css:Written inside a style tag in the head of the same HTML file.
3.External css:Written in a separate .css file and linked to the HTML.
